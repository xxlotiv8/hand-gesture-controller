# Hand Gesture Controller

The browser prototype tracks an index finger with MediaPipe. To control the
macOS cursor outside the browser, compile and run the native helper:

```bash
open GestureMouse.app
```

Then open `index.html`, click **Start camera**, and grant **Gesture Mouse**
Accessibility permission in **System Settings > Privacy & Security >
Accessibility** if macOS asks. Point to move, pinch to press and hold the left
mouse button, and separate the fingers to release it.
